## Doc Uploader 개발

1. 기술 스택
- React + Vite + Django + FastAPI

2. API 설계
- ht_tools 프로젝트에 dev_marker 프로젝트의 Marker(PDF 변환용), Markitdown(MS 오피스 문서 등)을 호출하는 FastAPI 구현

3. UI/UX 설계
	(1) ht_tools 앱 랜딩페이지 : 'Doc Uploader' 타일메뉴 추가
	
	(2) Doc Uploader 앱 구현 상세
	
		(2-1) 문서변환 작업 현재 상태 영역		
		- 앱 진입하면 항상 문서 변환 작업 대기열 현재 상태 표시(실시간)
		- 다른 사용자가 추가한 작업도 출력
		- 다른 사용자가 작업을 추가하면 그 작업을 실시간 반영하여 보여줌
		- 컬럼명 정의 : 작업순서번호, 파일명, 추가된 날짜, 작업상태(working / waiting / completed), 정상완료여부(정상/실패)
		- 작업 추가한 사용자 id 를 목록에 출력할 필요는 없음
		- 목록이 길어지면 스크롤바 표시
	
		(2-2) 파일 업로드 영역
		- MS 오피스 파일(.docx, .pptx 등), PDF 파일 업로드 가능
		- 일반 .txt 파일은 단순 .md 파일로 확장자 변경
		- .md 파일은 변환없이 사용자가 지정한 카테고리로 저장
		
		(2-3) 문서 분류 카테고리(저장 폴더) 지정
		- 문서 저장 폴더 위치 root는 ~HOME/doc_data/ 폴더
		- 현재 존재하는 카테고리(폴더) 목록(폴더명, 파일갯수) 표시
		- 사용자는 새로운 폴더를 생성, 이름변경할 수 있음
		- 폴더 삭제는 불가(추후 관리자 메뉴로 구현할 예정으로 지금은 구현 안함)
		- 폴더 생성, 변경시 이름은 Windows OS 의 표준 규칙으로 검사

3. 서버 자원의 효율적인 사용
- 대기열 리프레시 목적으로 프로세스 과다 소모 방지
